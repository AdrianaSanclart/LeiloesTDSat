# LeiloesTDSat

## Sobre o Projeto

O LeiloesTDSat é um sistema desktop desenvolvido para uma casa de leilões, com o objetivo de auxiliar no cadastro e na consulta de produtos disponíveis para venda.

O projeto foi desenvolvido como parte das atividades do curso Técnico em Desenvolvimento de Sistemas do SENAC.

## Tecnologias Utilizadas

- Java
- Java Swing
- MySQL
- JDBC
- NetBeans IDE
- Git
- GitHub
